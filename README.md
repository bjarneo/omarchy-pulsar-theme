# Pulsar

A vibrant cosmic theme for [Omarchy Quattro](https://github.com/omacom/omarchy).

## Install

```bash
omarchy theme install https://github.com/bjarneo/omarchy-pulsar-theme
```

## Optional Neovim Theme

`neovim.lua` configures OneDark for manual use. Omarchy does not install Lua from third-party themes.
